# 管理播客

## 添加
1. 进入添加播客页面
![播客设置截图](/images/manage-1.png)
2. 填写播客信息，上传播客音频文件和图片，填写完毕后点击【发布】
![播客设置截图](/images/manage-2.png)

## 编辑
1. 进入编辑播客页面
![播客设置截图](/images/manage-3.png)
2. 编辑播客信息后，点击【保存】
![播客设置截图](/images/manage-4.png)

## 字段说明

| 字段名称 | 说明 |
|---|---|
| 音频文件 <span style="color: red;">*</span> | 必填。音频媒体库字段，只能选择音频文件；保存的值为媒体附件 ID。 |
| 时长（秒） | 只读数字字段。保存后从“音频文件”自动识别，单位为秒。 |
| 音频长度（字节） | 只读数字字段。保存后从“音频文件”自动识别，单位为字节。 |
| 音频 MIME 类型 | 只读字段。保存后从“音频文件”自动识别，默认值为 `audio/mpeg`。 |
| 内容分级 <span style="color: red;">*</span> | 必填。选择 `clean`（无露骨内容）或 `explicit`，默认值为 `clean`。 |
| 剧集类型 | 选择 `full`、`trailer` 或 `bonus`，默认值为 `full`。代码帮助文本标记为必填，但当前代码未设置 Carbon Fields 的必填校验。 |
| 集数 | 可选，但推荐填写。数字字段，最小值为 `0`，整数。 |
| 季数 | 可选。数字字段，最小值为 `0`，整数。 |
| 剧集作者（覆盖） | 可选。覆盖当前剧集使用的频道作者。为空时使用播客设置中的作者。 |
| 剧集封面（正方形） | 可选。媒体库图片字段，建议使用 1400–3000px 的正方形图片；保存的值为媒体附件 ID，并覆盖频道封面。 |
| 文字稿（可选） | 可选。URL 输入框（`type=url`），填写文字稿文件 URL，支持 `vtt`、`srt`、`txt`、`pdf` 等格式。 |
| iTunes 标题（可选） | 可选。文本字段，覆盖 Apple Podcasts 的 `<itunes:title>`。 |
| 章节（Podcasting 2.0） | 可选。URL 输入框（`type=url`），填写章节 JSON 文件的 URL，用于生成 `<podcast:chapters>`。 |
| 章节 MIME 类型 | 可选。章节文件的 MIME 类型，默认值为 `application/json+chapters`。 |
| 剧集音频片段（Podcasting 2.0） | 可选复合字段，可添加一个或多个 `<podcast:soundbite>`。每个片段包含开始时间（秒，最小值 `0`，步长 `0.01`）、持续时间（秒，最小值 `0.01`，步长 `0.01`）和可选标题。 |
| 副标题 | 可选。文本区域，用于填写 iTunes 简短副标题。 |
| 摘要 | 可选。文本区域，用于填写 iTunes 纯文本摘要。 |
| 自定义 GUID（可选） | 可选。自定义 RSS GUID；留空时使用 WordPress 剧集固定链接。 |
| iTunes 屏蔽 | 可选。选择 `yes` 时在 Apple Podcasts 中隐藏该剧集，默认值为 `no`。 |
| 成员 | 可选的多选字段，只显示具有作者（`author`）角色的用户；新建剧集时，当前作者角色用户默认选中自己。 |
| 嘉宾 | 可选的多选字段，只显示具有订阅者（`subscriber`）角色的用户。 |

## 注意事项
- 带 <span style="color: red;">*</span> 的字段在代码中调用了 `set_required(true)`。
- `剧集类型` 的帮助文本写明为必填，但当前代码没有调用 `set_required(true)`；未填写时 RSS 会使用 `full` 作为剧集类型。
